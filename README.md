# 图像净修

在 Windows 10 或 11 上双击 `LocalImageRepair.exe` 即可运行。软件使用系统自带的 .NET Framework，处理过程在本机完成。

1. 点击「打开图片」，或将图片拖入窗口。支持 PNG、JPG、BMP 和 TIFF，每次处理一张图片。
2. 点击「自动修复」，软件会在右下角识别样图中的两种半透明「豆包AI生成」字样（带描边的白字和无描边的灰字），并复查附近的叠加字样及「AI生成」残留。如果字样在其他位置，点击「框选位置」，拖动框住整行字样和少量周边。
3. 切换「原图」和「修复后」对照效果。可点击「放大检查」或使用滚轮缩放，按住鼠标右键拖动可平移。
4. 点击「另存为 PNG」，在系统保存窗口中指定文件名和目录。导出保留原图像素尺寸。

软件通过匹配字形和估计半透明叠加还原底图。多层重叠处会参考周围像素补全纹理，放大后可能与原来的细节不同。效果取决于字样的样式、图片压缩程度以及背景细节。样式差异较大时可能无法匹配。最大支持 4,000 万像素，单边不超过 16,000 像素。

浅色背景上的带描边白字会单独校准填充和描边，以减少纸面上的字影和 JPEG 压缩产生的杂色。

如需从源码重新构建，可在 PowerShell 中运行 `./build.ps1`。
